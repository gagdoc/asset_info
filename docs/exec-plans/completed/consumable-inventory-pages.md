# 현재 재고와 월별 마감 재고 페이지 분리

- 마스터 및 추적 관리에서 월 선택과 스냅샷 조회를 제거하고 현재 품목/입출고/입고 이력 기능을 유지한다.
- 기존 브라우저의 monthly 요청도 품목 API에서는 현재 재고를 반환한다. 과거 재고는 monthly-report 전용 API를 사용한다.
- /consumables/closing-inventory 별도 페이지와 사이드바 메뉴를 추가한다. 마감된 월, 당시 추적 품목, 저장 시각, 현재 재고와 증감, 엑셀 내보내기를 제공한다.
- 마감 버튼은 출고 페이지에 유지한다. 마감 시 스냅샷 저장 로직은 변경하지 않는다.
- 검증: 현재 품목 및 이전 월별 요청의 동일 수량, 마스터/추적 화면 표시, 월 선택 제거, 별도 페이지 빈 상태와 스냅샷 표시. 테스트 서비스에만 배포한다.
