# 자산 목록 열 선택·순서 설정

리스트 도구 모음의 `열 보기·순서`에서 열별 표시 여부를 선택하고 ↑/↓로 왼쪽부터의 순서를 변경한다. 모두 표시, 기본 구성 복원, 완료 버튼을 제공한다. 상세 수정은 원본 columns를 계속 사용하므로 숨긴 열도 편집할 수 있다.

기존 hidden_columns_<type> 설정을 유지하고 column_order_<type>을 별도로 저장한다. 브라우저·자산 종류별로 설정이 유지되며 다른 장치와 동기화하지 않는다. 삭제/중복 열은 순서에서 제외하고 새 열은 뒤에 추가한다. 최소 한 열을 표시한다. 손상된 저장값은 기본 구성으로 처리한다.

검증: Vite 빌드, 목록 정규화(삭제·중복·신규 열), 순서 이동·저장, 열 숨김/표시, 마지막 열 보호 실행 검사. 상세 수정과 표 헤더·셀의 열 목록 분리 확인.
