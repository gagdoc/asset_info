# 월 마감 재고 분리

운영 원본 유지, 테스트 소스/복사 시트에서만 작업한다.

현재 재고: 기존 E/F 입고 기준과 일반 출고/대여 및 토너 실재고를 읽는 단일 서비스 계산을 모든 화면이 공유한다. 새 월 생성은 출고 탭만 만들고 마스터 E/F를 수정하지 않는다. 테스트 전환 기준월은 사용자 확인 사례와 9월 조회 결과를 기준으로 2026년 9월로 명시 설정한다. 미리 생성된 10월 탭을 기준으로 삼지 않는다. 9월 및 이후 월 출고를 누적 차감하며, 기준월 미설정 시 조회에서 자동 생성하지 않고 오류로 처리한다. 과거 전체 이력을 새로 차감하거나 실제 수량을 추정 보정하지 않는다.

마감: 추적 대상 품목의 당시 현재고/명칭/분류/단가/출고량을 별도 스냅샷에 고정 저장. 조회는 저장된 값만 읽고 마스터나 토너 재고를 수정하지 않는다. 이전 형식의 시작재고는 마감재고로 추정 표시하지 않는다.

현재 재고와 마감월 조회를 명시적으로 분리하고 과거 화면은 읽기 전용. 마감은 신규/수정/삭제 모두 차단한다. 마감 해제는 지원하지 않는다. V2 스냅샷 저장을 마감 상태의 기준으로 삼아 부가 상태 시트 저장 실패에도 출고를 차단한다. 현재 월만 신규 마감할 수 있고 이후 월 거래가 있으면 거부한다. 과거 스냅샷은 소급 생성하지 않는다.

검증: 새 월/마감/조회/재조회 후 마스터 값 및 현재고 불변, 다음달 입출고 후 스냅샷 불변, 미추적 제외, 0/음수 보존, 실패시 마감 미완료, 기존 저장/인증/격리 회귀.
